# WhiteRoad - Taller de Motos

## Nota sobre Validación W3C

El archivo `detalle.html` genera un warning de "Section lacks heading" en la validación W3C estática del HTML. **Esto se resuelve automáticamente cuando la página se carga** porque el contenido de la sección se genera dinámicamente con JavaScript, que incluye un heading (h2) con el nombre del servicio. El validador solo analiza el HTML estático sin ejecutar JavaScript, por lo que no detecta el heading generado.

En tiempo de ejecución (cuando abris la página en el navegador), la estructura semántica es correcta y cumple con los estándares W3C. <3
